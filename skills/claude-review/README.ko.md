# Claude Review

Codex가 현재 작업의 요구사항과 허용된 코드 자료를 준비하고, 로컬 Claude Code CLI에 독립 리뷰를 요청하는 스킬입니다. 기본값은 `--model opus --effort xhigh`이며, 요청 시 모델과 추론 강도를 바꿀 수 있습니다. `opus`는 고정 버전이 아닌 별칭입니다.

## 설치와 사용

이 폴더를 사용하는 에이전트의 스킬 디렉터리에 복사하세요. Codex에서는 `${CODEX_HOME:-$HOME/.codex}/skills/claude-review`에 둘 수 있습니다. 같은 이름의 스킬이 있다면 내용을 비교한 후 기존 변경을 보존하세요.

Claude Code가 설치되어 있고 해당 계정에서 요청한 모델을 사용할 수 있어야 합니다. 설치만으로 모델을 호출하거나 로그인·결제·전역 설정을 변경하지 않습니다. 사용량과 비용은 연결된 계정 및 제공자 조건에 따릅니다.

```text
$claude-review 현재 작업의 요구사항에 맞춰 변경 내용을 검토해줘.
$claude-review 모델은 sonnet, effort는 high로 검토해줘.
$claude-review 권한 검사 변경 부분을 검토하고 한국어로 알려줘.
```

기존 스킬의 명시적 호출 정책을 유지합니다. `agents/openai.yaml`의 `allow_implicit_invocation: false`로 일반 작업마다 자동 호출되지 않도록 설정되어 있습니다.

## 동작과 범위

Codex는 저장소 밖의 별도 임시 디렉터리에 검토 자료를 준비합니다. Claude는 도구 없이 그 자료만 검토하고, 소스 수정·명령 실행·테스트·커밋을 하지 않습니다. 구현 담당자는 발견 사항을 실제 코드와 대조한 후 원래 작업에서 승인된 수정과 검증을 수행합니다. 검토만 요청했다면 수정까지 자동으로 시작하지 않습니다.

검토 자료는 Claude Code에 설정된 제공자에게 전달됩니다. 프로젝트의 외부 전송 제한을 따르며, 비밀정보·고객 데이터·운영 기록을 그대로 포함하지 않습니다. 이 스킬의 도구 제한은 운영체제 수준의 격리를 보장하지 않습니다.

CLI 옵션의 존재는 `claude --help`로 확인합니다. 인증·모델 접근·옵션 호환성 문제가 있으면 이유를 보고하며, 권한을 우회하거나 다른 모델로 조용히 대체하지 않습니다. 요청한 모델·effort와 실행 결과에서 확인되는 실제 설정을 구분합니다.

영문 [SKILL.md](SKILL.md)에 검토 자료 구성, 실행 예시, 결과 확인 절차가 있습니다. 실행 예시의 정적 검증 범위는 스킬·YAML 구조, 셸 문법, 설치된 `claude --help`의 옵션 존재 여부입니다. 이 검증만으로 실제 모델 접근이나 리뷰 품질을 확인한 것으로 간주하지 않습니다.
